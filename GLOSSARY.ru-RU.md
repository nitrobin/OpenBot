# Глоссарий русской документации OpenBot DIY

Этот файл задаёт терминологию для русских инструкций по механической сборке, электронике, 3D-печати, прошивке и вводу OpenBot DIY в эксплуатацию. При переводе и последующих правках используйте приведённые здесь варианты единообразно.

## Правила перевода

1. Используйте принятый русский технический термин для описания деталей и действий. Обозначения контактов, разъёмов, сигналов, параметров и пунктов интерфейса всегда приводите в исходном написании. Русское пояснение добавляйте рядом; оно не заменяет маркировку. Например: `GND` (общий провод), `Echo` (эхо-сигнал), `Wall Line Count` (число линий стенки).
2. Сохраняйте названия изделий, библиотек, файлов, команд, макросов и сигналов: `Arduino Nano`, `ESP32`, `L298N`, `DIY_ESP32`, `TICKS_PER_REV`, `OUT1`, `Echo`, `Trigger`, `GND`. Регистр букв, цифры и знаки также сохраняйте: `D0` и `DO` — разные записи. Не переводите текст внутри команд и примеров протокола.
3. Названия пунктов интерфейса Arduino IDE, Android Studio и слайсера сохраняйте на английском, как на иллюстрациях. Перед названием можно добавить русское пояснение: «монитор последовательного порта (`Serial Monitor`)».
4. Различайте корпус и шасси, двигатель и мотор-редуктор, колесо и шину, разъём и его отдельный контакт, аккумулятор и аккумуляторную батарею. Не заменяйте точные понятия общим словом «модуль».
5. Указывайте единицы после числа с пробелом: `5 В`, `150 Ом`, `20 кОм`, `0,2 мм`, `80 мм/с`, `50 %`. Размеры записывайте через знак умножения: `240 × 150 мм`, `M3 × 25`. В коде, URL и именах файлов исходную запись сохраняйте.
6. Переводите `rpm` как «об/мин», а не «обороты в секунду». Для относительной длительности импульса ШИМ используйте «коэффициент заполнения». Скважность — обратная величина; эти термины не взаимозаменяемы.
7. При каждом упоминании общего провода обязательно указывайте `GND`: `GND` (общий провод) или общий провод (`GND`). В этой документации это опорный потенциал схемы; обозначение `GND` само по себе не подразумевает защитное заземление `PE`.
8. Сохраняйте последовательность операций, полярность, номера выводов, номиналы, размеры и предупреждения. Если исходная инструкция противоречит коду, указывайте проверенное уточнение отдельно, со ссылкой на файл; не скрывайте исправление внутри перевода.
9. Новые переводы добавляйте как `README.ru-RU.md` рядом с другими локализациями. Связывайте русские инструкции между собой, сохраняя ссылки на исходные модели, схемы, фотографии и английские документы, у которых ещё нет перевода.

## Как читать обозначения контактов и разъёмов

В инструкции по подключению указывайте **точную маркировку обоих концов соединения и название каждой платы**. Например: «соедините `SCL` OLED-дисплея с `A5` Arduino Nano». Одного русского названия функции контакта недостаточно для определения места подключения.

| Исходное обозначение | Пояснение | Что нужно различать |
| --- | --- | --- |
| `GND` | Общий провод (`GND`) | В схеме OpenBot к нему подключается минус питания; защитное заземление обозначается `PE`. |
| `5V`, `+12V`, `3V3` | Обозначения цепей питания | Сохраняйте запись с конкретной платы. Напряжение питания и допустимый уровень сигнала — разные характеристики. |
| `VIN`, `Vin`, `VCC` | Обозначения питания конкретного узла | Назначение и допустимое напряжение определяются документацией этой платы. `VIN` OLED-дисплея, `VIN` Arduino и `Vin` специализированной PCB относятся к разным узлам; их нельзя объединять общим переводом «питание». |
| `D2`, `D3`, `A4`, `A5`, `A7` | Обозначения выводов Arduino Nano | Название `D2` на Arduino Nano не означает `GPIO2` ESP32. Для другой платы требуется её собственная схема выводов. |
| `D0` | Обозначение, зависящее от устройства | В текстовой инструкции `D0` датчика частоты вращения обозначает его цифровой выход. В схеме DIY он подключается к `D2` или `D3` Arduino Nano, а не к одноимённому `D0` Arduino. Всегда называйте устройство вместе с контактом. |
| `GPIO` | Вывод ввода-вывода микроконтроллера | Номер GPIO относится к сигналу микроконтроллера, а не обязательно к порядковому номеру контакта на разъёме платы. |
| `OUT1`, `OUT2`, `OUT3`, `OUT4` | Выходы драйвера L298N | Сохраняйте номера и указанную в инструкции полярность подключения двигателей. |
| `M1`, `M2`, `M3`, `M4` | Разъёмы двигателей на специализированной PCB | Здесь `M3` — маркировка разъёма. В строке «винт M3 × 25» `M3` обозначает метрическую резьбу, а не разъём. |
| `Echo`, `Trig`, `Trigger` | Сигналы ультразвукового дальномера | Сохраняйте написание из конкретной схемы и маркировки. Русское «эхо» или «запуск» само по себе не является именем контакта. |
| `SCL`, `SDA` | Тактовая линия и линия данных I2C | Это две разные линии; в инструкциях оставляйте `SCL` и `SDA`, даже если рядом есть русское пояснение. |
| `SONAR`, `SPEED_L`, `SPEED_R`, `SIGNAL_L`, `SIGNAL_R`, `IO2` | Маркировка разъёмов специализированной PCB | Сохраняйте обозначения целиком. Суффиксы `_L` и `_R` различают левую и правую стороны. |
| `PIN_VIN`, `PIN_ECHO`, `PIN_TRIGGER` | Имена настроек в прошивке | Это программные имена, а не обязательно надписи на плате. Например, `PIN_VIN` задаёт вход измерения напряжения через делитель; это не указание подключать батарею к контакту `VIN` микроконтроллерной платы. |

Источники конкретных соединений: [инструкция DIY](body/diy/README.ru-RU.md) и блок выбранной аппаратной конфигурации в [прошивке](firmware/openbot/openbot.ino). Назначение контактов Arduino Nano и ESP32 описывается отдельно; одинаковые слова в их названиях не задают одинакового подключения.

**Различие маркировки в исходных материалах:** питание OLED-дисплея в текстовой инструкции названо `VIN`, а на [схеме соединений](docs/images/wiring_diagram.png) — `VCC`. При работе с конкретным модулем сверяйте его маркировку и допустимое питание с документацией этого модуля. Такое расхождение не является основанием считать `VIN` и `VCC` взаимозаменяемыми на всех платах.

## Управление, датчики и программное обеспечение

| moving average; median filter | скользящее среднее; медианный фильтр | Первое усредняет несколько отсчётов; второй выбирает срединное значение упорядоченного набора и помогает подавлять одиночные выбросы. |
| heartbeat | сообщение контроля активности | Подтверждает активность управляющего устройства. |
| state of charge; SOC | степень заряженности; SOC | Оценка доли оставшегося заряда. Напряжение батареи в вольтах и SOC в процентах — разные величины. |
| controller; game controller | пульт управления; игровой контроллер | Для платы электроники используем «контроллер» или «плата управления» по контексту. |
| teleoperation | дистанционное управление | Управление роботом оператором по каналу связи. |
| API level; SDK | уровень API; комплект средств разработки SDK | Номер API Android задаёт версию программного интерфейса. SDK содержит средства сборки и разработки. |
| minSdkVersion; compileSdkVersion; targetSdkVersion | `minSdkVersion`; `compileSdkVersion`; `targetSdkVersion` | Минимальный API устройства, API для сборки и целевой API поведения приложения соответственно. Эти настройки выполняют разные задачи; имена сохраняйте. |
| build; deploy | собрать приложение; установить и запустить | Не смешиваем сборку приложения с механической сборкой. |
