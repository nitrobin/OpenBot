# Съёмный блок распределения питания Nano / L298N

[Открыть схему в Fritzing](openbot-diy-power-hub.fzz). Батарейный блок и выключатель подключаются отдельными двухконтактными разъёмами. Между распределителем и **одним L298N проходят три провода**: питание батареи к `+12V`, общий `GND` и выход `5V` L298N обратно к распределителю. Отдельный блок «источник 5 В» убран.

![Распределитель Nano / L298N с подписями всех контактов](openbot-diy-power-hub.png)

[Принципиальная схема в PNG](openbot-diy-power-hub-schematic.png). Во вкладках **Breadboard** и **Schematic** одинаковые электрические соединения. Оба вида экспортированы в SVG штатным Fritzing 1.0.8; PNG получены из этих экспортов через Inkscape. Компоненты, графика и редактируемые провода включены в `.fzz`.

Распределитель внутри `.fzz` содержит 17 внешних контактов, две внутренние точки пайки под R1 / R2, четыре внутренние цепи и оба вида. **Полный блок с резисторами находится в `.fzz`**: R1 и R2 — отдельные редактируемые компоненты внутри контура платы; при переносе блока в другую схему копируй их вместе с распределителем и измерительными проводами. Эта версия предназначена для [сборки Arduino Nano](README.ru-RU.md). У [ESP32](README.esp32.ru-RU.md) другая схема питания с двумя DC/DC и питанием FC-03 от `3V3`.

## Контакты и второй конец провода

Все контакты подписаны по подключаемому блоку. `5V L298N` — **вход** распределителя от **выхода** `5V` L298N в режиме `5V-EN ON`. `VBAT L298N` — **выход** распределителя после выключателя, который соединяется с контактом `+12V` L298N; надпись `+12V` — маркировка платы.

| Разъём / контакт | Имя контакта в Fritzing | Другой конец провода |
| --- | --- | --- |
| `J1.1` | `BAT+` | Плюс батарейного блока |
| `J1.2` | `GND BAT` | Минус батарейного блока (`GND`) |
| `J2.1` | `SW_IN` | `IN` / `COM` выключателя `SW1` |
| `J2.2` | `SW_OUT` | `OUT` / выбранный переключаемый контакт выключателя `SW1` |
| `J3.1` | `VBAT L298N` | `+12V` L298N |
| `J3.2` | `GND L298N` | `GND` L298N |
| `J3.3` | `5V L298N` | `5V` L298N — выход встроенного стабилизатора |
| `J4.1` | `5V OLED` | `VIN` OLED-дисплея (`VCC` на исходном рисунке) |
| `J4.2` | `GND OLED` | `GND` OLED-дисплея |
| `J4.3` | `5V HC-SR04` | `VCC` ультразвукового дальномера HC-SR04 |
| `J4.4` | `GND HC-SR04` | `GND` ультразвукового дальномера HC-SR04 |
| `J4.5` | `5V FC-03 L` | `VCC` левого датчика FC-03 |
| `J4.6` | `GND FC-03 L` | `GND` левого датчика FC-03 |
| `J4.7` | `5V FC-03 R` | `VCC` правого датчика FC-03 |
| `J4.8` | `GND FC-03 R` | `GND` правого датчика FC-03 |
| `J4.9` | `A7 NANO` | `A7` Arduino Nano — измерение батареи через встроенный делитель |
| `J4.10` | `GND NANO` | `GND` Arduino Nano |
| Внутренняя точка пайки | `VBAT R1` | Контакт `1` резистора R1 **20 кОм**, вход делителя после `SW1` |
| Внутренняя точка пайки | `GND R2` | Контакт `2` резистора R2 **10 кОм**, нижний конец делителя батареи |

`J4` содержит четыре пары `5V` / `GND` для OLED и датчиков и пару **`A7 NANO` / `GND NANO`**. Нумерация идёт сверху вниз, сначала левый контакт, затем правый. Ранее свободное место рядом с `GND NANO` теперь занято выходом `A7 NANO`. Контакта `5V NANO` нет; питание Nano приходит по USB/OTG. `VBAT R1` и `GND R2` расположены внутри блока и служат для пайки встроенных резисторов, а не для кабеля к внешнему делителю.

**У `J2 SW` оба провода находятся в цепи плюса батареи; контакта `GND` там нет.** Используй выключатель или кнопку **с фиксацией**. На рисунке подключены `COM` и один переключаемый контакт; второй переключаемый контакт `L2` свободен.

## Внутренние соединения

Распределитель собран на перфорированной макетной плате. Цветные дорожки в Breadboard показывают соединения на нижней стороне платы. Сами отверстия такой платы между собой не соединены.

| Цепь | Соединённые контакты |
| --- | --- |
| Плюс до выключателя | `BAT+` ↔ `SW_IN` |
| Плюс после выключателя | `SW_OUT`, `VBAT L298N`, `VBAT R1` |
| Общий `GND` | `GND BAT`, `GND L298N`, `GND OLED`, `GND HC-SR04`, `GND FC-03 L`, `GND FC-03 R`, `GND NANO`, `GND R2` |
| Стабилизированные 5 В | `5V L298N`, `5V OLED`, `5V HC-SR04`, `5V FC-03 L`, `5V FC-03 R` |

Путь питания: **батарея `+` → `BAT+` → `SW_IN` → `SW1` → `SW_OUT` → `VBAT L298N` → `+12V` L298N**. Выход `5V` L298N → `5V L298N` распределителя → OLED и датчики. При `OFF` или отсоединении кабеля `SW1` плюс батареи отключается от L298N и R1. Общий `GND` остаётся соединённым. Цепи `VBAT` и `5V` внутри распределителя не соединены; распределитель не снижает напряжение.

## Встроенный делитель и выход A7

Внутри того же блока установлены **R1 20 кОм** и **R2 10 кОм**. `VBAT R1` после выключателя → контакт `1` R1; контакт `2` R1 → контакт `1` R2 и выход `A7 NANO`; контакт `2` R2 → `GND R2`. Бирюзовые провода показывают измерительную цепь. Соедини `A7 NANO` распределителя с **`A7` Arduino Nano**, а `GND NANO` распределителя — с **`GND` Arduino Nano**.

Напряжение на `A7` равно **VBAT × 10 / (20 + 10) = VBAT / 3**. При 12,6 В на батарее получается 4,2 В на `A7`. Вход делителя подключён после `SW1`; при `OFF` измерительная точка связана с `GND` через R2. `A7` только измеряет напряжение батареи и не питает Nano.

Nano питается по **USB/OTG**, её `5V` и `VIN` свободны. Этот делитель заменяет внешние R1 / R2 из [полной схемы Nano](openbot-diy-nano.fzz): при использовании нового блока не подключай второй делитель параллельно `A7`.

## Режим питания L298N

**Техническое уточнение.** Здесь показан режим с установленной перемычкой **`5V-EN`**: `5V` L298N работает как **выход** встроенного стабилизатора. При снятой перемычке этот контакт становится входом внешних 5 В; показанное направление питания тогда не применяется. Назначение контакта описано в [руководстве Handson Technology](https://handsontec.com/dataspecs/L298N%20Motor%20Driver.pdf).

В том же руководстве встроенный источник разрешён при питании ниже 12 В. Показанный батарейный блок 3S достигает **12,6 В**, поэтому перед сборкой проверь допустимое напряжение своего конкретного модуля. Если его руководство требует внешний DC/DC для 3S, используй соответствующий вариант питания из [инструкции Nano](README.ru-RU.md#технические-уточнения): он требует иной схемы источника `5V`. Условия работы стабилизатора не меняются от добавления распределителя.

Силовой ток всех мотор-редукторов проходит через `J1`, `J2`, контакт `J3.1`, контакт `J3.2`, провода и выключатель. Выбирай их по пусковому току моторов. В изображении `J1` / `J2` использованы силовые разъёмы XT30, а для `J3` — готовая графика трёхконтактной винтовой колодки. Положение деталей служит для чтения соединений; производственная разводка PCB не предусмотрена.

## Проверка и источники

[validate_topology.py](validate_topology.py) проверяет все 19 электрических контактов распределителя, четыре внутренние цепи, **ровно три провода L298N**, отсутствие выхода питания Nano и совпадение соединений Breadboard и Schematic. Отдельно проверяются номиналы R1 / R2, последовательность **VBAT → R1 → A7 → R2 → GND**, отсутствие провода в обход резисторов и расположение обоих резисторов внутри блока. Проверка `OFF` и отсоединённого `SW1` подтверждает разрыв питания L298N / R1. Также проверяется изоляция `5V` от `VBAT` и `GND`. [Отчёт проверки](topology-validation.json).

Соединения датчиков и OLED соответствуют [исходной инструкции OpenBot DIY](../README.md#option-1-diy) и [исходной картинке](../../../docs/images/wiring_diagram.png). У исходной Nano контакт `5V` свободен; питание приходит по USB. Четыре существующие схемы Nano / ESP32 также проверяются отдельно, с исправлением ранее добавленного лишнего провода Nano `5V`.
