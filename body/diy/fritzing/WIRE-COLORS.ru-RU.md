# Цвета проводов в схемах OpenBot

Одна палитра применяется к схемам **Arduino Nano** и **ESP32** во вкладках **Schematic** и **Breadboard**, а также в превью PNG. Внизу каждой схемы находится легенда с образцами цветов. Цвет обозначает назначение провода; подключение определяют по маркировке контактов.

| Назначение | Цвет | HEX |
| --- | --- | --- |
| `VBAT` — плюс аккумуляторной батареи | Красный | `#c62828` |
| `5V` — питание 5 В | Оранжевый | `#ef6c00` |
| `3V3` — питание 3,3 В | Розовый | `#ec407a` |
| `VMOT` — питание L298N после преобразователя | Серо-синий | `#546e7a` |
| `GND` — общий провод (`GND`) | Чёрный | `#202124` |
| Выходы L298N `OUT1`–`OUT4` к мотор-редукторам | Коричневый | `#795548` |
| `PWM` — управление L298N `IN1`–`IN4` | Золотистый | `#b08b00` |
| Цифровые сигналы датчиков частоты вращения `D0` / `DO` | Зелёный | `#228833` |
| Сигналы дальномера `Trig` / `Echo`, включая делитель `Echo` | Синий | `#0077bb` |
| `I2C` — OLED `SCL` / `SDA` | Фиолетовый | `#7b2cbf` |
| `LED` — управление светодиодами поворотников | Пурпурный | `#b52ca4` |
| `ADC` — измерительная часть делителя батареи | Бирюзовый | `#008577` |

Провода питания и `GND` датчиков имеют цвет соответствующей цепи питания, а сигнальные провода — цвет функции датчика. Например, `VCC` дальномера — оранжевый (`5V`), `GND` — чёрный, `Trig` и `Echo` — синие. В схеме Nano питание моторов непосредственно от батареи относится к `VBAT`; в ESP32 выход отдельного преобразователя относится к `VMOT`.

Легенда включает типы из обеих схем: не все из них используются в каждом варианте. Поворотники и OLED в схеме ESP32 отключены.

Цветная легенда включена в каждый файл `.fzz`. При редактировании в Fritzing используй цвета из этой таблицы, чтобы назначения проводов совпадали во всех схемах.
