## Самостоятельная сборка

Для работы с программным обеспечением OpenBot можно собрать любое колёсное шасси с микроконтроллером, например Arduino Nano. Разработчики подготовили [корпус для 3D-печати](diy/README.ru-RU.md), рассчитанный на недорогие и доступные компоненты для любительской робототехники. [OpenBot Lite](lite) — уменьшенный и упрощённый вариант OpenBot DIY для обучения. Даже если вы не планируете собирать Lite, его [пошаговые видеоинструкции](lite/#step-by-step-video-guides) могут быть полезны. Также разработан [корпус для 3D-печати](rc_truck) для серийных радиоуправляемых грузовиков масштаба 1:16, например [этой модели](https://www.amazon.de/dp/B00M3J7DJW). Для проектов на открытом воздухе доступны чертежи [вездеходной платформы](mtv) на базе OpenBot.
